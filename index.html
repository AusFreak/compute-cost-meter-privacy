Privacy Policy

Compute Cost Meter for ChatGPT

Effective date: 5 October 2026

Compute Cost Meter for ChatGPT is a browser extension that estimates the compute hardware and electricity cost associated with the time taken for ChatGPT to generate a response.

Data the extension uses

The extension detects user interaction necessary to identify when a ChatGPT request is sent and when response generation begins and ends.

The extension does not collect, store, or transmit the contents of ChatGPT prompts or responses.

Data stored locally

The extension stores the following information locally in Chrome extension storage:

  • Selected currency
  • Selected display mode
  • Cumulative estimated cost
  • Cumulative measured response time
  • Number of measured requests
  • The most recent request cost and time summary

This information is used solely to provide the extension's counter and settings.

Data transmission

The extension does not transmit user data, ChatGPT conversation content, browsing history, settings, or measurement data to the developer or any third party.

The extension does not contain analytics, advertising, telemetry, or tracking.

Location

The extension may infer a default currency from the browser's language or locale. It does not request or collect precise location information.

Data deletion

Users can delete locally stored counter data by selecting Reset counter in the extension. Removing the extension will also remove its local extension storage according to browser behaviour.

Third-party relationship

Compute Cost Meter for ChatGPT is an independent extension and is not affiliated with, sponsored by, or endorsed by OpenAI.
